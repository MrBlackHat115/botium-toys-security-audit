# Botium Toys Security Audit

## Project Overview

- This project is an educational internal security audit of Botium Toys, a fictional U.S. toy company.
- The purpose of the audit was to review the company's security posture, identify security risks, evaluate existing security controls, assess selected PCI DSS compliance practices, and provide security recommendations.
  - **Note**: Botium Toys is a fictional company used for educational purposes as part of the Google Cybersecurity Certificate. This project is a portfolio presentation of my analysis and is not an audit of a real organization.

## Audit Objectives

- The main objectives of this security audit were to:

  - Identify and review company assets
  - Assess existing security risks
  - Evaluate current security controls
  - Identify missing or weak controls
  - Review selected PCI DSS compliance practices
  - Recommend improvements to Botium Toys' security posture

## Conclusion
- The assessment found that Botium Toys has several foundational security controls in place, including a firewall, antivirus software, physical locks, CCTV surveillance, and fire detection/prevention systems.

- However, significant security gaps remain. The highest-priority improvements are protecting sensitive payment information, limiting access through least privilege, implementing encryption, creating backups and disaster recovery procedures, strengthening password security, and improving security monitoring.

- Addressing these issues would help reduce the organization's overall risk and improve the confidentiality, integrity, and availability of its systems and data.
